# HAW015

Reports an unused source configuration/options property when the containing
type is configuration-shaped: its name ends with `Options`, `Settings`, or
`Configuration`, a configured suffix, or it is used as the payload of a
recognized `IOptions<T>` family type.

The default scope is private properties. Assignments and initializers are not
meaningful reads; a property used by a branch, invocation, or other behavior is
kept. Properties with attributes are conservatively treated as binder or
reflection targets, and public properties are never reported. Set
`includeInternalProperties` to `true` only when the internal configuration
surface is closed to external binders.

Configure `configurationTypeSuffixes` to add project-specific configuration
roles. HAW015 is enabled by default; configuration binding and reflection can
still occur outside the analyzed source compilation, so use its documented
scope options when reviewing results.
