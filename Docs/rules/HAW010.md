# HAW010

Reports a small source class with a service-style suffix, exactly one eligible
public ordinary method, at most the configured number of source callers, and
no implemented interface. The default suffixes are `Service`, `Handler`,
`Processor`, and `Validator`; the defaults are 25 physical method lines,
cyclomatic complexity 2, and one source caller.

A suffix needs a non-empty domain prefix, so a generic type named simply
`Service` is not classified as a service-style type.

HAW010 counts distinct source calling methods, not invocations or external
assembly consumers. It excludes abstract classes, interface implementations,
overrides, types with additional public operations, and methods that exceed the
size or complexity limits. The diagnostic is a review signal to co-locate a
tiny operation with its cohesive owner; it does not prescribe merging unrelated
responsibilities.

Configure `serviceSuffixes`, `maximumPhysicalLines`,
`maximumCyclomaticComplexity`, and `maximumSourceCallers`. If the small class
is a required registration or dispatch boundary, use a local justified
suppression:

```csharp
[SuppressMessage(
    "Hawthorne.Architecture",
    "HAW010",
    Justification = "Command dispatcher registration requires this explicit boundary.")]
```
