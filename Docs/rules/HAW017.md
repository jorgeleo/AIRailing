# HAW017

Reports an immediate `System.Linq.Enumerable.ToList` or `ToArray` whose result
immediately feeds another supported `System.Linq.Enumerable` operation that
works on `IEnumerable<T>`. The initial follow-up set includes filtering,
projection, ordering, partitioning, terminal checks/counts, first/single, and
a second materialization.

The rule uses Roslyn operation and symbol information; it does not infer LINQ
from method text. It does not report materialization that is stored, returned,
indexed, mutated, or passed to a non-LINQ/List-only API. This avoids changing
semantics at collection-boundary operations.

Configure `analyzeToList` and `analyzeToArray` independently. If materializing
is required before a provider or translation boundary, use a local justified
suppression:

```csharp
[SuppressMessage(
    "Hawthorne.Reliability",
    "HAW017",
    Justification = "Provider requires materialization before its translation boundary.")]
```
