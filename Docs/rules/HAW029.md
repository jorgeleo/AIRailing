# HAW029 — Excessive logging noise

Reports a source type when at least five eligible methods contain a
recognized logger call whose compile-time template contains an entry/exit/
success lifecycle term, and the ratio reaches the configured 80% threshold.
Logger symbols are preferred over spelling. Error, warning, critical,
exception-bearing, audit, metric, and business-state logs are excluded.

The rule is enabled by default. Options are `minimumMethodCount`, `maximumLifecycleLogRatio`,
`lifecycleTerms`, and `loggerTypeNames`. Keep logs for operationally useful
events rather than removing diagnostic context wholesale.
