# HAW018

Reports a source method parameter or local enumerable when it is definitely
consumed at least twice in the same method-body block. Initial consumers are
`foreach`, LINQ terminal operations, `ToList`/`ToArray`, and an explicit
`GetEnumerator` call. The default `minimumEnumerations` is two.

Arrays, strings, and generic collection/read-only collection/list types are
excluded because repeated enumeration is not the same risk for those
collections. Reassigning the tracked enumerable to its own `ToList` or
`ToArray` result resets the local evidence, since later reads operate on a
materialized collection.

This first implementation intentionally does not make a cross-branch or
cross-method control-flow claim. Configure `minimumEnumerations` to raise the
reporting threshold, and materialize once at the ownership boundary when the
enumerable is expensive or one-shot.
