# HAW106

Reports a block-bodied method that contains multiple executable statements
entirely on one physical line. It ignores expression-bodied methods and
multiline method bodies. Braces and semicolons inside expressions, including
string interpolation, do not trigger diagnostics by themselves. The rule is
enabled by default and only reports diagnostics; it never edits source files
automatically.

Disable it in `hawthorne.json` if a project does not want this warning:

```json
{
  "version": 1,
  "rules": {
    "HAW106": {
      "enabled": false,
      "severity": "warning"
    }
  }
}
```

The potential fix is to put each method statement on its own line and format
the method body across multiple lines.

HAW106 is non-suppressible. Expand the method body across multiple lines;
HAW901 reports a source suppression as an error.
