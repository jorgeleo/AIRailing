# HAW106

Reports an opening curly brace (`{`) or semicolon (`;`) that is not immediately
followed by a carriage return and line feed (`\r\n`). The rule is opt-in and
only reports diagnostics; it never edits source files automatically.

Enable it in `hawthorne.json`:

```json
{
  "version": 1,
  "rules": {
    "HAW106": {
      "enabled": true,
      "severity": "warning"
    }
  }
}
```

The potential fix is to place `\r\n` immediately after each reported token.

HAW106 is non-suppressible. Apply the required CRLF formatting; HAW901 reports
a source suppression as an error.
