# HAW024

Reports a `CancellationToken` parameter that is neither read nor forwarded. It
also reports a call that omits an available token when the selected target
method accepts one, or that explicitly supplies `CancellationToken.None` by
default.

The missing-forwarding diagnostic takes precedence over a second unused-token
diagnostic for the same method. Token checks such as
`ThrowIfCancellationRequested`, registration, and forwarding to a compatible
callee count as use. Calls to overloads that do not accept a token are not
reported.

Configure `reportMissingForwarding`, `treatNoneAsMissingForwarding`, and
`ignoreContractMethods`. Contract methods are excluded by default because their
shape may be required by an interface or override. Prefer propagating the
available token to cancellable work, or remove it from a boundary that cannot
honor cancellation.

```csharp
[SuppressMessage(
    "Hawthorne.Reliability",
    "HAW024",
    Justification = "Legacy callback has no cancellable downstream operation.")]
```
