# HAW025 — Configuration pass-through

Reports a configuration/options parameter forwarded unchanged across at least
two source method boundaries. The compilation-wide flow index follows typed
parameter edges and reports the first boundary with later boundaries as
related locations. Reads, validation, conversion, selection, and non-source
contracts are outside this initial conservative signal.

The rule is enabled by default. Options are `minimumForwardingHops` (default 2)
and `configurationTypeSuffixes`. Consume or
validate configuration at the boundary, or suppress with a justified
`SuppressMessage` when pass-through is an intentional contract.
