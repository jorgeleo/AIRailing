# HAW020 — Boilerplate repository layer

Reports a repository/store/DAO type when one EF Core `DbSet` or
`DbContext` dependency receives at least three eligible public methods and the
configured forwarding ratio (default 80%) is met. Recognition uses symbols;
method selection, mapping, transactions, authorization, caching, and domain
behavior are not counted as pass-throughs.

The rule is enabled by default. Configure `minimumForwardingMethods`,
`minimumForwardingRatio`, `repositorySuffixes`, and `requireRepositorySuffix`.
Repository boundaries can still be intentional; fix by removing the empty
layer or adding the policy/domain behavior that makes the boundary real.
Suppress only with a justified `SuppressMessage` when the boundary is a
documented contract.
