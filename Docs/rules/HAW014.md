# HAW014

Reports a direct null guard on a non-nullable reference parameter only when the
analyzer can prove that every direct source invocation supplies that parameter
with `NullableFlowState.NotNull`. It recognizes `x == null`, `x is null`,
`ReferenceEquals(x, null)`, and `ArgumentNullException.ThrowIfNull(x)` before
the parameter is otherwise read.

The default scope is private ordinary methods. Public, protected, virtual,
interface, overridden, nullable, `[AllowNull]`, uncalled, and method-group or
delegate-invoked methods are excluded. A nullable, omitted, unknown, or
indirect call makes the proof incomplete and suppresses the diagnostic. This
is a redundancy signal, not a claim that boundary validation is generally
wrong.

Set `includeInternalMethods` to `true` only when the compilation boundary is
known to include every internal caller. A justified local suppression remains
appropriate for private reflection or serialization entry points:

```csharp
[SuppressMessage(
    "Hawthorne.Architecture",
    "HAW014",
    Justification = "Private reflection entry point remains supported by the serializer.")]
```
