# HAW030 — Copy-paste near duplication

At compilation end, compares source methods with at least three statements and
reports one diagnostic per cluster of at least three methods whose deterministic
operation-shape similarity reaches 0.90 by default. Identifiers and literals
are normalized; related locations identify the other cluster members.

The rule is enabled by default. Options are `minimumMethods`, `minimumStatements`, and `minimumSimilarity`.
Overrides, interface implementations, trivial accessors, generated code, and
small clusters are excluded. Review a reported cluster before extracting an
abstraction; mapping code can be legitimately repetitive.
