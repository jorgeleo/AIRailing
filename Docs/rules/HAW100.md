# HAW100 — Abstraction density

Emits one informational health metric at compilation end:

`abstraction types / behavioral types`.

Abstractions include interfaces, abstract classes, and configured role suffixes
(`Factory`, `Adapter`, `Facade`, `Provider`, `Manager`, `Service`). Behavioral
types are concrete classes with meaningful ordinary methods. Each source type
is counted once. `abstractionCount`, `behavioralCount`, and an invariant
`density` are available as diagnostic properties.

The rule is enabled by default. Set `minimumBehavioralTypes` to avoid noisy
small projects. Optional
`maximumDensity` reports only when the measured density exceeds that threshold;
without it, the diagnostic is a measurement. Persist trends in CI rather than
inside the analyzer.

HAW100 is non-suppressible. Simplify the measured abstraction structure or
adjust the reviewed project threshold; HAW901 reports a source suppression as
an error.
