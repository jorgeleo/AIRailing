# HAW104

Reports class coupling above `maximum` (default 12), excluding primitives and common wrappers. Generic type arguments count as dependencies, and members of nested types are not attributed to their enclosing type.

The diagnostic includes a deterministic sample of counted types and category counts for API surface, state/dependency, and implementation sources. A type used by several categories counts once toward the threshold. Categories explain the result; they do not change the total-based trigger or configuration semantics.

HAW104 remains a review signal rather than an instruction to split every high-count type.

HAW104 is non-suppressible. Simplify the type by separating cohesive
responsibilities and narrowing dependencies; HAW901 reports a source
suppression as an error.
