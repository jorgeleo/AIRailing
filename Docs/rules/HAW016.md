# HAW016

Reports task-returning methods that expose asynchronous semantics without doing
asynchronous work. The default detection covers `async` methods with no
`await`, `Task.FromResult`, `Task.CompletedTask`, and direct `ValueTask`
construction from a synchronous value.

Interface implementations and overrides are ignored by default because their
async shape may be a required contract. Set `ignoreContractMethods` to `false`
only after calibrating that choice for the consuming project. Genuine
asynchronous operations such as `Task.Delay` are not reported.

`reportTrivialTaskRun` is disabled by default. When enabled it reports only a
single literal-returning `Task.Run` lambda; it does not make a general claim
about server workload or scheduler policy. Prefer a synchronous return when no
asynchronous boundary exists, or add the real asynchronous operation that the
API promises.

If a framework callback requires an otherwise fake asynchronous shape, suppress
the rule locally with a specific non-blank justification:

```csharp
[SuppressMessage(
    "Hawthorne.Reliability",
    "HAW016",
    Justification = "Framework callback requires a Task-returning signature.")]
```
