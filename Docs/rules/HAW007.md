# HAW007

Reports a source constructor with more service-like dependencies than
`maximumDependencies` (default 7). The rule counts class and interface
parameters, while excluding scalar values, enums, value types, arrays,
configuration-shaped type names, and—by default—`IOptions<T>`,
`IOptionsSnapshot<T>`, and `IOptionsMonitor<T>`.

Use `configurationTypeSuffixes` to declare local configuration naming
conventions and `excludeOptionWrappers` to control the Microsoft options
wrappers. Constructors are measured independently; HAW007 does not combine
dependencies across overloads or infer a dependency from its parameter name.

Prefer splitting unrelated responsibilities or extracting a cohesive
collaborator. A composition-root adapter can be intentional; suppress it only
at that constructor with a specific non-blank justification:

```csharp
[SuppressMessage(
    "Hawthorne.Architecture",
    "HAW007",
    Justification = "Composition root adapter for the legacy host boundary.")]
```
