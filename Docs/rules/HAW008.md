# HAW008

Reports a method when boolean parameters directly control multiple separate
branches. By default two distinct controlling parameters produce a warning and
three produce an error. An explicit configured `severity` overrides that
default escalation.

HAW008 recognizes direct use in conditionals, loops, conditional expressions,
and switch guards. A parameter passed to a helper is not direct by default;
set `requireDirectControlFlowUse` to `false` only after calibrating that broader
interpretation. Overrides and interface implementations are excluded because
the caller already owns their contract.

Configure `warningParameterCount`, `errorParameterCount`, and
`requireDirectControlFlowUse`. The error count must be greater than or equal
to the warning count. Prefer focused operations, an explicit options type, or
an intentional behavior model over independent control flags. If a protocol
requires the flags, use a justified local suppression:

```csharp
[SuppressMessage(
    "Hawthorne.Architecture",
    "HAW008",
    Justification = "Legacy wire protocol requires independent behavior flags.")]
```
