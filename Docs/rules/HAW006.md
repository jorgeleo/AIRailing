# HAW006

Reports a source-defined abstract class when it has no significant shared state
or behavior and the source demonstrates only one use of that abstraction. A
use is either one distinct concrete derived class or, for a generic abstract
class, one distinct fully closed generic construction. When both forms are
present, HAW006 emits one diagnostic and describes both pieces of evidence.

By default, a concrete method or constructor with more than two executable
statements is significant shared behavior. A source field, concrete property,
or event is treated as shared state and also excludes the type. Abstract
members, constants, framework types, external derived types, and open generic
uses do not count as evidence.

Configure `maximumSharedExecutableStatements`, `minimumDerivedTypes`, and
`analyzeSingleClosedGenericUse` in the HAW006 rule object. The default derived
type threshold is one; values above one deliberately widen the low-use review
signal to that exact number of source implementations.

This is a conservative review signal, not a directive to remove intentional
plugin or framework extension contracts. When a public boundary must remain
abstract before a second implementation is available, suppress it locally with
a specific non-blank justification:

```csharp
[SuppressMessage(
    "Hawthorne.Architecture",
    "HAW006",
    Justification = "Public plugin contract is published independently of its first implementation.")]
```
