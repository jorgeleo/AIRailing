# HAW013

Reports a catch block that does no handling other than wrap the caught exception
in a configured generic exception. By default the configured replacement types
are `System.Exception` and `System.ApplicationException`. A literal message
does not add structured context, so it does not prevent the diagnostic.

HAW013 ignores rethrows, catch blocks that recover or mutate state, specific
domain exception types, and wrappers that add a non-literal context value. The
optional `reportLogAndRethrow` signal is disabled by default; when enabled it
reports a catch block whose only work is a `Log*` call containing the exception
followed by a rethrow.

Configure `genericExceptionTypes` and `reportLogAndRethrow`. Prefer preserving
the original exception, translating it to a meaningful domain exception, or
adding context the caller can act on. When a legacy API requires the generic
exception, suppress the specific method with a non-blank justification:

```csharp
[SuppressMessage(
    "Hawthorne.Reliability",
    "HAW013",
    Justification = "Legacy public API contract exposes ApplicationException.")]
```
