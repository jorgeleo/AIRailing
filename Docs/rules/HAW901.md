# HAW901

Reports `#pragma warning disable` directives that name HAW rules, codeless
disables that suppress every warning, and Hawthorne `SuppressMessageAttribute`
uses with a blank justification. Use `SuppressMessageAttribute` with a
non-blank `Justification` only for an intentional suppression of a rule that
permits it.

HAW100–HAW106 are tagged as non-suppressible because their detected condition
has a code simplification or formatting remedy. HAW900 and HAW901 are also
non-suppressible governance diagnostics: configuration errors must be
corrected, and suppression validation must remain active. An attempted
`SuppressMessageAttribute` or `#pragma` suppression of any of these IDs is an
error HAW901, even if the attribute includes a justification or
`hawthorne.json` disables HAW901. HAW901 reports its own attempted suppression
without a source location so the attempted suppression cannot hide the error.

| Policy | Rule IDs | HAW901 result |
| --- | --- | --- |
| Simplification or formatting | HAW100–HAW106 | Error; simplify or format the code. |
| Governance | HAW900, HAW901 | Error; correct configuration or keep validation active. |
| Review with an external-boundary case | HAW001–HAW030 | Warning for an invalid suppression; a specific justified attribute is permitted. |

For every other rule, HAW901 remains a warning by default when the
`SuppressMessageAttribute` justification is blank or when a `#pragma` is used.
Those rules may be suppressed locally only with a specific, non-blank
justification describing the real external contract, protocol, provider,
reflection boundary, or compatibility obligation.
