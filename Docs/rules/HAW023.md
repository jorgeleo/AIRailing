# HAW023 — Dead extension point

Reports a private event, delegate callback property, or virtual hook
with no source consumer. Private members are analyzed by default; externally
accessible members are excluded because a compilation cannot prove that an
external consumer does not exist. Source subscriptions, assignments, and
derived types prevent a report.

The rule is enabled by default. Options are `includePrivateMembers`,
`includeExternallyAccessibleMembers`,
`analyzeEvents`, `analyzeCallbacks`, and `analyzeVirtualHooks`. Remove unused
flexibility or add the demonstrated consumer. Suppress only with a specific
justification when an external contract intentionally has no in-compilation
consumer.
